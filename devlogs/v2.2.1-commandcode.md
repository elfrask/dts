# DTS v2.2.1 — Proveedor CommandCode integrado

**Fecha**: 23/07/2026

## Contexto

La v2.2 introdujo proveedores personalizados, pero configurar uno a mano para
CommandCode implicaba pelear con dos protocolos distintos: sus modelos abiertos
responden en `/v1/chat/completions` y los Claude **solo** en `/v1/messages`.
Además la URL base del SDK de Anthropic necesita un ajuste diferente al de
OpenAI. Resultado: configuraciones frágiles.

Solución: integrar CommandCode como proveedor de primera clase, con enrutado
automático por modelo.

## Qué es CommandCode

Un agregador que expone todos los modelos principales detrás de un único API key:

- **OpenAI-compatible**: `https://api.commandcode.ai/provider/v1`
- **Anthropic Messages**: `https://api.commandcode.ai/provider` → `/v1/messages`
- **Catálogo**: `GET https://api.commandcode.ai/provider/v1/models`

## Implementación

### Datos

- `ProviderType.COMMANDCODE = "commandcode"`.
- `COMMANDCODE_BASE_URL` y `COMMANDCODE_ANTHROPIC_BASE_URL` en `defaults.py`.
- `COMMANDCODE_MODELS` como respaldo estático; el catálogo real se consulta en vivo.
- Añadido a `BUILTIN_PROVIDERS`, `PROVIDER_MODELS` y `OPENAI_COMPATIBLE_BASE_URLS`.

### Proveedor

```python
class CommandCodeProvider(OpenAICompatibleProvider):
    def __init__(self, api_keys, known_models=None):
        super().__init__(..., base_url=COMMANDCODE_BASE_URL, ...)
        self._anthropic = AnthropicProvider(
            api_keys=api_keys,
            base_url=COMMANDCODE_ANTHROPIC_BASE_URL,
            provider_name="commandcode",
        )

    def translate_batch(self, items, prompt, config, on_progress=None):
        if str(config.model).lower().startswith("claude"):
            return self._anthropic.translate_batch(items, prompt, config, on_progress)
        return super().translate_batch(items, prompt, config, on_progress)
```

- **Enrutado**: `claude-*` → Anthropic SDK (`/provider/v1/messages`); todo lo
  demás → OpenAI SDK (`/provider/v1/chat/completions`).
- **Modelos**: `fetch_commandcode_models()` consulta `/models` y descarta los
  modelos de decisión `typesafe/*`.
- **Retry**: el primer intento usa `response_format=json_object`; los reintentos
  lo omiten para endpoints que no lo implementan.

### UI

- Lista de proveedores: **CommandCode** aparece primero.
- Pestaña de configuración: una sola API key y lista de modelos recomendados.
- Pestaña Traducir: botón **"Actualizar modelos"** trae el catálogo completo.

### CLI

```bash
dts config --provider commandcode --add-key "cmd_..."
dts config --show
dts settings --provider commandcode --model deepseek/deepseek-v4.1-flash
```

`config --add-key` ahora acepta `--provider` (antes solo funcionaba con Gemini).

## Fix: se eliminó la dependencia del SDK `openai`

Durante las pruebas apareció este error incluso con una key válida:

```
cannot import name 'types' from partially initialized module 'openai'
```

Causa raíz: la instalación local de `openai` 2.45.0 estaba incompleta (faltaba
todo el directorio `site-packages/openai/types/`), por lo que `import openai`
fallaba antes de hacer ninguna petición. No era un problema de CommandCode ni de
los proveedores personalizados.

Solución: se reemplazó el SDK por un cliente HTTP mínimo sobre `urllib` de la
stdlib (`src/core/http_client.py`) para todos los proveedores OpenAI-compatible:

- `POST {base_url}/chat/completions` con `Authorization: Bearer <key>`
- `GET {base_url}/models`
- Errores HTTP con cuerpo incluido para diagnóstico
- Timeout de 180 s para chat, 60 s para listados

Beneficios: ya no se depende de un paquete generado grande y frágil; funciona en
cualquier instalación de Python 3.11+. `openai` se quitó de `requirements.txt` y
`pyproject.toml`. El SDK de `anthropic` se mantiene para la ruta `/messages`.

## Uso

1. Obtén una API key en `https://commandcode.ai/settings/keys`.
2. **Configuración global → Proveedor de IA → CommandCode** y pégala.
3. En el proyecto, pestaña **Traducir**, elige `commandcode` y pulsa
   **Actualizar modelos**.
4. Selecciona p. ej. `deepseek/deepseek-v4.1-flash` (OpenAI) o `claude-sonnet-5-5`
   (Anthropic). El enrutado es automático.
