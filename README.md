# DTS v2 — Dialogue Translation System

Traductor de diálogos de videojuegos (GameMaker) del inglés al español usando APIs de IA.

![Captura 1 de la app](screenshots/1.png)

## Uso rápido

```bash
# CLI
dts help

# GUI (sin argumentos)
dts
```
